sheet2sound
==========

Paper sheet music to sound: scan upload -> Audiveris OMR (patched) -> MusicXML ->
vexml/VexFlow 5 canvas -> Tone.js + MusyngKite SoundFont, with a human verification
stage for OMR corrections.
